# SUTRA - AICTE Grievance & Case Monitoring Dashboard

SUTRA is the centralized, role-based complaint monitoring, intelligent triage, and institutional surveillance web portal for the All India Council for Technical Education (AICTE).

## Features
- **Executive Dashboard**: Real-time cross-bureau KPIs, SLA radars, and dwell-time bottleneck analytics.
- **Smart Case Register**: Search, filter, paginate, and track grievance lifecycles with state machine enforcement.
- **Explainable AI Triage & Master Tickets**: Zero-shot routing, duplicate grouping, and bulk resolution cascade.
- **Student Grievance Portal**: Secure OTP-authenticated complainant tracking and evidentiary document upload for Awaiting Information tickets.
- **Institutional Trust Score Leaderboard**: Real-time regulatory penalty rating and downloadable official PDF show-cause notices.
