<objective>
Build the backend CSV ingestion and export engine featuring dry-run pre-validation with row-by-row error diagnostics, transaction-safe atomic batch commitment, and role-scoped CSV export with automatic confidentiality redaction.

Purpose: Allow institutions and AICTE grievance cells to ingest historical and batch grievances cleanly while enabling authorized personnel to export filtered compliance records.
Output: Pydantic schemas, CSV I/O service, API endpoints in cases router, and automated pytest suite.
</objective>
