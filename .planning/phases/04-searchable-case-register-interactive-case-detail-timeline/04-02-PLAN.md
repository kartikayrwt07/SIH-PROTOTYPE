  <name>Build CaseTransitionModal with guard verification and mandatory remarks</name>
  <files>
    frontend/src/components/cases/CaseTransitionModal.tsx
  </files>
  <action>
    Create frontend/src/components/cases/CaseTransitionModal.tsx:
    - Modal dialog displaying current case status.
    - Computes permissible next states based on 9-state transition matrix:
      * Received -> Registered
      * Registered -> Under Triage
      * Under Triage -> Assigned
      * Assigned -> In Progress
      * In Progress -> Awaiting Information, Under Review
      * Awaiting Information -> In Progress
      * Under Review -> In Progress, Resolved
      * Resolved -> Closed, In Progress (Reopen)
      * Closed -> terminal
    - Action dropdown / selector of available transitions.
    - Mandatory remarks textarea with character counter.
    - Submits via `transitionCase()` or `reopenCase()` and invokes `onSuccess()`.
  </action>
  <verify>
    <automated>npm --prefix frontend run build</automated>
  </verify>
  <done>Transition modal enforces valid state selections and captures mandatory rationale.</done>
