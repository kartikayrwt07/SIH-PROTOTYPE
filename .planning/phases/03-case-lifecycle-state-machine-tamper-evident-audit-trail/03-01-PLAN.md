  <action>
    Create backend/app/services/audit.py:
    - log_case_event(db, case_id, actor, event_type, previous_state, new_state, metadata): persists CaseAuditEvent in database.
    Create backend/app/services/lifecycle.py:
    - ALLOWED_TRANSITIONS map defining all valid state movements:
      * Received -> Registered
      * Registered -> Under Triage
      * Under Triage -> Assigned
      * Assigned -> In Progress
      * In Progress -> Awaiting Information, Under Review
      * Awaiting Information -> In Progress
      * Under Review -> In Progress, Resolved
      * Resolved -> Closed, In Progress (Reopen)
      * Closed -> terminal
    - can_transition(from_state, to_state) -> bool
    - get_allowed_transitions(from_state) -> List[CaseStatus]
    - execute_transition(db, case, to_status, actor, remarks):
      * validates transition; raises HTTPException(422) if invalid
      * updates case status, timestamps (resolved_at, closed_at)
      * invokes log_case_event to append immutable audit record
    Write tracer tests in backend/tests/test_lifecycle.py.
  </action>
  <verify>

  </verify>
